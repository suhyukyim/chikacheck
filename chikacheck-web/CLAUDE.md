# 치카체크 웹 — AI 코딩 규칙

이 저장소는 4팀 사업 아이디어 「치카체크」(어린이 정량 치약 디스펜서 + 양치 기록 웹)의 **발표용 시연 프로토타입**이다.
작업 전에 항상 아래 문서를 기준으로 삼는다.

- 기능·규칙·데이터: `docs/PRD.md`
- 색·레이아웃·문구: `docs/DESIGN.md`
- 단계별 작업 순서: `docs/PIPELINE.md`

## 반드시 지킬 것
1. **Vanilla JS (ES Modules)만** 쓴다. React·Vue·jQuery·Tailwind·TypeScript·npm 패키지·빌드 도구 금지.
   외부 리소스는 Pretendard 폰트 CDN 하나만 허용.
2. 데이터는 `js/store.js`를 통해서만 읽고 쓴다. 다른 파일에서 `localStorage`를 직접 호출하지 않는다.
3. 계산 로직(slot, 달력 상태, 실천율, 스탬프, 단계, 퀘스트)은 `js/domain/`에 **순수 함수**로 둔다.
   - DOM·localStorage·`Date.now()`를 직접 쓰지 않고, 현재 시각은 `now` 인자로 받는다 (테스트 가능하게).
4. 기기(본체)와의 통신은 `js/device/device.js` 규약으로만 한다. 화면 코드가 시뮬레이터를 직접 import하지 않는다.
5. 색·간격·반경은 `css/tokens.css`의 CSS 변수로만 쓴다. hex 색을 다른 파일에 쓰지 않는다.
6. 날짜·시간은 **한국 시간(Asia/Seoul) 로컬 시각** 기준. 주는 **월요일 시작**.
7. 화면 문구는 한국어. 아이 화면은 반말·짧게, 부모 화면은 존댓말 (DESIGN.md 8장).
8. 접근성: 버튼은 `<button>`, 아이콘 버튼엔 `aria-label`, 타이머 숫자엔 `aria-live="polite"` (1초마다 읽지 않도록 구역 바뀔 때만 갱신되는 별도 영역에).
9. 콘솔 에러 0개 유지. `console.log`는 커밋 전에 지운다 (`tests.html` 제외).

## 하지 말 것
- PRD 1.3 "범위에서 제외" 항목(로그인, 서버, 결제, 센서, 실제 BLE, 여러 아이 프로필 등)을 임의로 추가하지 않는다.
- 현재 단계에 없는 기능을 미리 만들지 않는다. 필요하면 `// TODO(stage-N):` 주석만 남긴다.
- 기존 파일을 통째로 다시 쓰지 않는다. 필요한 부분만 고친다.
- 기존 캐릭터·브랜드 이미지(디즈니, 산리오, 포켓몬 등)를 쓰거나 비슷하게 그리지 않는다.

## 작업 방식
- 각 단계 시작 시: 해당 단계의 **범위 / 만들 파일 / 완료 기준**을 먼저 3~5줄로 요약하고 시작한다.
- 각 단계 끝에: 완료 기준 체크리스트를 하나씩 ✅/❌로 보고하고, 사람이 직접 확인할 방법(어느 화면에서 뭘 누르면 되는지)을 적는다.
- 애매한 건 PRD를 따르고, PRD에도 없으면 **추측하지 말고 질문**한다.
- 단계가 끝나면 커밋 메시지를 제안한다: `stage-N: 한 줄 요약`

## 실행
- VSCode **Live Server** 확장으로 `index.html` 열기 (주소 예: `http://127.0.0.1:5500/`)
- 테스트: `http://127.0.0.1:5500/tests.html` → 모두 PASS인지 확인
