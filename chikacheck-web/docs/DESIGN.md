# 치카체크 디자인 가이드

> 기준: 제안서 2-2 화면 시안 3장 + 본체 디자인(크림색 토끼 본체, 민트 칫솔 컵, 코랄 포인트).
> 모든 색·간격은 `css/tokens.css`의 변수로만 쓴다. 코드에 색 hex를 직접 쓰지 않는다.

## 1. 색 토큰

| 변수 | 값 | 용도 |
|---|---|---|
| `--bg` | `#FBF4EC` | 앱 배경 (크림) |
| `--surface` | `#FFFFFF` | 카드 |
| `--line` | `#EFE3D3` | 카드 테두리, 구분선 |
| `--ink` | `#2B2520` | 본문 글자 |
| `--ink-sub` | `#8C8177` | 보조 글자 |
| `--green` | `#1E9E6E` | 완료, 진행 링, 주요 버튼 |
| `--green-soft` | `#E3F4EC` | 배지 배경, 보상 카드 배경 |
| `--coral` | `#EE8A73` | 현재 구역, 짧음(주황), 강조 |
| `--coral-soft` | `#FDEDE8` | 안내 카드 아이콘 배경 |
| `--purple` | `#9B7BD8` | 충치균 |
| `--gray` | `#E6DED3` | 남은 구역, 예정 칸, 링 바탕 |
| `--pink` | `#F6B9B9` | 캐릭터 볼, 귀 안쪽 |
| `--danger` | `#D9534F` | 초기화 등 위험 버튼 |
| `--toy-tooth` `--toy-gum` `--toy-gum-top` | `#FFFFFF` `#FFC6D3` `#FFD9E2` | 입 지도(장난감 치아 모형) 이빨·잇몸 |
| `--toy-hot` `--toy-hot-deep` | `#BDF0DE` `#5FCFAA` | 지금 닦는 면 (민트 — 분홍 잇몸과 구분되게) |
| `--tooth` `--tooth-line` | `#FFFDF8` `#D9C8B2` | 이빨 친구 몸·테두리 |
| `--cheek-skin` `--tongue` `--tongue-mouth` `--blush` | | 볼·혀 캐릭터, 볼터치 |
| `--foam` `--foam-line` `--bristle-line` | | 칫솔 거품·솔 |

입 지도·이빨 친구는 **무섭지 않게**: 진한 핏빛 잇몸·어두운 입속·혀 대신 파스텔 장난감 치아 모형처럼, 그림자는 약하게.

다크 모드: 이번 시연에서는 **지원하지 않는다** (아이용 밝은 화면 고정). `<meta name="color-scheme" content="light">`.

## 2. 타이포그래피
- 폰트: `Pretendard Variable`, 대체 `system-ui, -apple-system, "Apple SD Gothic Neo", sans-serif`
- CDN: `https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css`

| 이름 | 크기/굵기 | 사용 |
|---|---|---|
| display | 56px / 800, `font-variant-numeric: tabular-nums` | 타이머 숫자 |
| title | 22px / 800 | 화면 제목 ("치카 타임") |
| stat | 28px / 800, 초록 | 부모 카드 숫자 (86%, 2분 48초) |
| body | 16px / 600 | 카드 제목 |
| caption | 13px / 500, `--ink-sub` | 보조 문구 |

## 3. 간격·모양
- 간격 단위 4px: `--s1:4px --s2:8px --s3:12px --s4:16px --s5:20px --s6:24px`
- 카드: 배경 `--surface`, 테두리 `1px solid var(--line)`, 반경 `18px`, 안쪽 여백 16px
- 배지(pill): 반경 999px, 배경 `--green-soft`, 글자 `--green` 12px/700
- 진행 바: 높이 8px, 반경 999px, 바탕 `--gray`, 채움 `--green`
- 터치 영역 최소 48×48px (아이 손가락)

## 4. 레이아웃
- 콘텐츠 최대 폭 **420px**, 가운데 정렬 (노트북에서도 폰처럼 보이게 — 발표 화면용)
- 노트북(≥ 900px): 폰 화면을 가운데. 가상 본체 패널은 **화면에 띄우지 않는다** (단축키 `T`·`D`로 대신)
- 하단 탭 바: 아이 프로필 `치카 타임` · `내 친구` (2칸) / 엄마·아빠 프로필 `치카 타임` · `내 친구` · `부모` (3칸). 로그인·프로필 선택 화면에서는 숨김
- 상단: 화면 제목(좌) + 상태 배지 + **프로필 버튼**(지금 프로필 이름 + 바꾸기 아이콘, 우)

## 5. 화면별 시안 대응

### 로그인 · 프로필 선택
- 로그인: 캐릭터 그림 + "치카체크" + 카드(아이디·비밀번호·초록 "로그인" 버튼) + 아래 "시연용 계정 · 아이디 chika · 비밀번호 1234"
- 프로필 선택: "프로필을 골라 주세요" + 2열 카드(96px 아바타 + 이름 + 보조 문구). 아이 = 캐릭터 그림(크림 배경), 엄마·아빠 = 두 사람 + 하트 그림(연초록 배경) + 🔒 "비밀번호"
- 2차 비밀번호: 자물쇠 아이콘 + "엄마·아빠 비밀번호" + 점 4개(채우면 초록) + 3열 숫자 키패드 + "프로필 다시 고르기"

### 치카 타임
1. 제목 "치카 타임" + 배지 "본체 버튼 연동"
2. 큰 카드: 원형 링(지름 200px, 두께 14px, 바탕 `--gray`, 진행 `--green`, 12시 방향 시작·시계방향 감소) + 가운데 `2:00` + "남은 시간". **양치 중에는 132px로 줄인다**
3. 이빨 친구 카드 (양치 중에만)
   - 가운데 큰 이빨 친구(눈·볼터치·웃는 입), 닦을 면이 민트색으로 깜빡, 칫솔 + 거품, 보라 충치균 3마리
   - 왼쪽 볼(살구색, 볼터치·감은 눈, "볼"), 오른쪽 혀(분홍, 눈·웃는 입, "혀") — 해당 쪽이면 진하게 + 통통, 아니면 흐리게
   - 오른쪽 위 "입 지도" 카드(폭 40%, 흰 바탕·테두리): 3D 장난감 치아 모형, 가운데 앞니에 눈·볼터치, 닦는 곳에 거품·노란 별
   - 아래 "지금은 아랫니 바깥쪽!"(20px/800) + "6구역 중 3번째 · 30초마다 닦을 곳이 바뀌어요"

### 내 치카 친구
1. 제목 "내 치카 친구" + 배지 "2단계 · 꼬마 치카"
2. 캐릭터 카드: 캐릭터 SVG(160px) + "다음 단계 **치카 히어로**까지 스탬프 6개" + 진행 바 + "성장하면 깜짝 아이템을 받아요"
3. 오늘의 출석: 동그라미 2개(56px). 완료=초록 채움+흰 글자, 미완료=점선 테두리 + 옆에 "저녁 양치하면 오늘 출석 완료!"
4. 이번 주 퀘스트: "저녁 양치 7일 연속 성공하기" + 우측 "4/7"(초록) + 진행 바

### 양치 달력 (부모)
1. 제목 "우리 아이 양치 기록"
2. 2열 카드: "이번 주 실천율 / **86%** / 14회 중 12회", "평균 양치 시간 / **2분 48초** / 목표 3분"
3. 이번 주 달력: 열 = 월화수목금토일, 행 = 아침/저녁. 점 22px
   - done: 초록 채움 / short: 코랄 테두리 2px + 흰 속 / upcoming: `--gray` 채움 / missed: `--gray` 테두리만
   - 오늘 열 위에 작은 점 표시
   - 범례 caption: "초록 완료 · 주황 짧음 · 회색 예정"
4. 보상 약속 카드: 배경 `--green-soft`, 테두리 초록 계열, 제목 "보상 약속" + 문구(연필 아이콘으로 편집)
5. 미양치 알림 카드: "미양치 알림" + "밤 9시까지 기록 없으면 알림" + 토글 스위치(초록)

## 6. 캐릭터
- **직접 그린 단순 도형 SVG**만 사용 (기존 캐릭터·브랜드 이미지 사용 금지 — 팀 결정: 유행 캐릭터는 확장 이후)
- 토끼(기본, 본체 디자인과 동일 컨셉): 크림 얼굴 원, 긴 귀(안쪽 핑크), 점 눈, 핑크 볼, 작은 웃는 입
- 곰·고양이: 같은 얼굴 틀에 귀 모양만 다르게
- 단계가 오를수록 소품 추가: 1단계 없음 → 2단계 리본 → 3단계 망토 → 4단계 왕관 (SVG `<g>` 레이어를 켜고 끄는 방식)

## 7. 움직임
- 기본 전환 200ms ease-out
- 구역 바뀔 때: "지금은 ○○!" 살짝 튀기(scale 1→1.04→1), 입 지도 카메라가 부드럽게 돌아감
- 양치 중: 칫솔 문지르기, 거품 뽀글, 충치균이 구역의 28%·56%·84% 지점에서 하나씩 사라짐, 88%부터 이빨 눈웃음
- 완료: 화면 전체 오버레이 + 캐릭터 점프 + 색종이(CSS만, 라이브러리 없이)
- `prefers-reduced-motion: reduce`이면 움직임 최소화

## 8. 문구 톤
- 아이 화면: 반말, 짧게, 느낌표 ("지금은 윗니 안쪽!", "다 닦았다!")
- 부모 화면: 존댓말, 정보 위주 ("이번 주 실천율", "기록이 없으면 알려드려요")
- 숫자는 아이 화면에서 최대한 크게, 글은 최대한 짧게
- 음성 안내도 아이 화면 말투(반말·짧게): "윗니 바깥쪽! 볼 쪽을 쓱쓱 닦아 보자!"
