# 치카체크 웹 PRD (발표용 시연 프로토타입)

> 4팀 사업 아이디어 제안서 「치카체크」의 웹·앱 파트를 실제로 동작하는 웹으로 구현한다.
> 하드웨어(디스펜서 본체)는 아직 없으므로 **화면 속 '가상 본체'** 로 버튼·LED를 흉내 낸다.

---

## 1. 목표와 범위

### 1.1 목표
- 제안서 2-3 사용 흐름 ①~⑥을 **발표장에서 끊김 없이 시연**할 수 있다.
- 제안서 2-2 화면 시안 3장(치카 타임 / 캐릭터 키우기 / 양치 달력)을 그대로 구현한다.
- 나중에 실제 BLE 보드를 붙일 수 있도록 **기기 연결부를 교체 가능한 구조**로 만든다.

### 1.2 범위에 포함
| 구분 | 기능 |
|---|---|
| 로그인·프로필 | 시연용 공동 계정 로그인, 프로필 선택(아이 / 엄마·아빠), 부모 2차 비밀번호 |
| 아이 화면 | 치카 타임(3분 타이머·이빨 친구 + 3D 입 지도로 6구역 안내·음성 안내·효과음), 내 치카 친구(캐릭터 성장·출석·스탬프·주간 퀘스트) |
| 부모 화면 | 이번 주 실천율, 평균 양치 시간, 주간 달력(아침/저녁), 보상 약속, 미양치 알림 |
| 가상 본체 | 타이머 버튼, 본체 LED(남은 시간 표시), 배출 버튼(시각 효과만) |
| 시연 도구 | 데모 데이터 채우기, 타이머 배속(×1/×10/×30), 데이터 초기화 |
| 배포 | GitHub Pages |

### 1.3 범위에서 제외 (이번엔 안 함)
- 실제 BLE(Web Bluetooth) 연결 → 구조만 열어둠 (부록 A)
- 회원가입·실제 계정 인증·서버·DB (localStorage만 사용) — 로그인은 **시연용 흉내**만 한다(3.0). 나중에 서버를 붙여 진짜 계정으로 확장
- 부모 목소리 직접 녹음 안내 (**검토 중**: 팀 의견을 듣고 결정. 지금은 브라우저 음성 합성만)
- 프리미엄 구독·결제 (팀 결정: 가벼운 무료 서비스)
- 칫솔 감지 센서·치약 배출량 감지 (팀 결정: 사용하지 않음)
- 유행 캐릭터 IP 적용 (팀 결정: 사업 확장 이후)
- 블록형 꾸미기 파츠 연동 (팀 결정: 보류)
- 여러 아이 프로필 (칫솔 걸이 1구 결정에 맞춰 **아이 1명** 기준)

## 2. 사용자와 핵심 흐름

### 2.1 사용자
- **아이 (만 3~6세)**: 글을 잘 못 읽음 → 큰 숫자, 그림, 색, 짧은 문장
- **부모**: 같은 기기(같은 브라우저)에서 '엄마·아빠' 프로필로 들어가(2차 비밀번호) 기록 확인·설정 변경. 아이 프로필의 모든 화면도 볼 수 있다

### 2.2 시연 흐름 (제안서 2-3과 1:1 대응)
0. 공동 계정으로 로그인 → 프로필 선택 *(처음 한 번. 다음부터는 프로필 선택부터)*
1. 칫솔을 거치대에서 꺼낸다 → *(설명만)*
2. 가상 본체 **배출 버튼** 클릭 → "완두콩만큼 나왔어요!" 효과 *(기록 안 함 — 실제 배출부는 기계식 래칫이라 전자 신호가 없음)*
3. 가상 본체 **타이머 버튼** 클릭 → 양치 1회 기록 생성 + 3분 타이머 시작
4. 본체 LED와 치카 타임 화면에 **같은 남은 시간** 표시, 30초마다 닦을 구역 변경 (그림 + 음성 안내)
5. 3분 완료 → 축하 효과, 스탬프 +1, 캐릭터 진행도 상승
6. 엄마·아빠 프로필 → 달력·실천율·평균 시간에 방금 기록 반영

## 3. 기능 명세

### 3.0 로그인·프로필 — `#/login`, `#/profiles`
- **시연용 흉내**: 서버가 없어서 아이디·비밀번호가 공개된 코드 안에 있다. 실제 비밀번호를 쓰지 않는다
- 로그인: 공동 계정 아이디 `chika` / 비밀번호 `1234` (아이디는 앞뒤 공백·대소문자 무시). 화면 아래 "시연용 계정" 안내
  - 틀리면 "아이디나 비밀번호가 맞지 않아요" + 흔들기, 비밀번호 칸 비움
  - 로그인 상태는 저장 → 다시 열면 **프로필 선택부터**
- 프로필 선택(넷플릭스 방식): **아이**(이름 = 아이 호칭, 캐릭터 그림) / **엄마·아빠**(이름은 설정에서 변경)
  - 아이: 누르면 바로 들어감
  - 엄마·아빠: **2차 비밀번호 4자리(`0000`)** 키패드. 틀리면 흔들기 + "비밀번호가 달라요" (아이의 실수 진입 방지)
  - 고른 프로필은 저장하지 않는다 (새로고침하면 다시 고름)
- 상단 오른쪽 **프로필 버튼**(지금 프로필 이름) → 누르면 프로필 선택으로
- 아이 프로필: 하단 탭 `치카 타임` · `내 친구`만. 부모 화면 주소로 가도 치카 타임으로 돌려보냄
- 엄마·아빠 프로필: 탭 3개 전부 + 설정. 아이 화면의 정보 변경(호칭·캐릭터 등)이 같은 저장소라 바로 반영
- 로그아웃: 설정 화면, 프로필 선택 화면
- 프로필을 고르기 전: 탭 바·알림 배너·가상 본체 숨김, 본체 타이머 버튼은 LED만 깜빡

### 3.1 치카 타임 (아이) — `#/timer`
- 원형 링 타이머: 3:00에서 감소, `m:ss` 표기, 아래 "남은 시간"
- 양치 중에는 링을 작게(132px) 줄이고, 아래 **이빨 친구 카드**에 닦을 곳을 그림으로 보여 준다
  - **이빨 친구**: 표정 있는 큰 이빨. 지금 닦을 면(바깥·안쪽·씹는 면)이 민트색으로 빛나고 칫솔이 문지른다. 윗니 구역이면 뿌리가 위로 가게 뒤집힌다(얼굴은 그대로)
  - 왼쪽 **볼**, 오른쪽 **혀** 캐릭터 — 바깥쪽이면 볼이, 안쪽이면 혀가 통통 튄다 (글자 못 읽는 아이용)
  - 구역마다 충치균 3마리가 차례로 사라지고, 다 사라지면 이빨이 눈웃음
  - **입 지도**(오른쪽 위): 장난감 치아 모형 같은 3D 그림(유치 20개). 닦는 면이 민트색으로 빛나고 거품·별이 어금니→앞니로 따라간다. 아랫니는 위에서, 윗니는 아래에서 비춘다
  - "6구역 중 N번째 · 30초마다 닦을 곳이 바뀌어요"
- 구역 순서 (30초씩)
  1. 윗니 바깥쪽 → 2. 윗니 안쪽 → 3. 아랫니 바깥쪽 → 4. 아랫니 안쪽 → 5. 윗니 씹는 면 → 6. 아랫니 씹는 면
- 안내 문구: "지금은 ○○!" (구역이 바뀔 때 살짝 튐)
- **소리** (설정에서 각각 끄기 가능, 기본 모두 켜짐)
  - 음성 안내: 구역마다 "윗니 바깥쪽! 볼 쪽을 쓱쓱 닦아 보자!" 등, 완료 "다 닦았어! 이가 반짝반짝해!", 그만하기 "다음엔 끝까지 닦아 보자!"
    - 브라우저 내장 음성 합성. 말투 '씩씩한'(높이 0.9, 빠르기 1.15), 목소리는 "Google 한국의" 우선, 없으면 기기 한국어 기본 목소리
  - 효과음: 띵동(구역 바뀔 때), 뽀글뽀글(양치 중), 배경 음악(직접 만든 짧은 멜로디, 음성 안내 때 작아짐). 완료 팡파레는 넣지 않음
  - 파일 없이 Web Audio로 직접 합성. 브라우저 정책상 사용자가 한 번 누른 뒤(타이머 버튼)에만 소리가 난다 → 새로고침 후 이어지는 양치는 조용할 수 있음
- 상단 배지 "본체 버튼 연동" (가상 본체 연결 상태 표시)
- 대기 상태: "본체의 타이머 버튼을 눌러 시작해요" + 화면용 시작 버튼(보조)
- 진행 중 "그만하기" 버튼 (확인 1회) → 기록은 남고 '짧음' 처리
- 완료 시: 축하 오버레이 + "스탬프 1개 받았어요"(해당 시간대 첫 완료일 때만)

### 3.2 내 치카 친구 (아이) — `#/friend`
- 캐릭터 일러스트(기본: 토끼 '치카') + 현재 단계 배지 "2단계 · 꼬마 치카"
- "다음 단계 ○○까지 스탬프 N개" + 진행 바 + "성장하면 깜짝 아이템을 받아요"
- 오늘의 출석: 아침 / 저녁 동그라미 (완료=채움, 미완료=점선)
- 이번 주 퀘스트: "저녁 양치 7일 연속 성공하기" N/7 + 진행 바

### 3.3 양치 달력 (부모) — `#/parent`
- 엄마·아빠 프로필에서만 열린다 (3.0의 2차 비밀번호가 부모 확인을 대신함)
- 상단 카드 2개
  - 이번 주 실천율 `%` + "N회 중 M회"
  - 평균 양치 시간 `m분 ss초` + "목표 3분"
- 이번 주 달력: 월~일 × 아침/저녁 점
  - 초록 = 완료, 주황 테두리 = 짧음, 회색 = 예정(아직 안 옴), 빈 회색 테두리 = 놓침
  - 범례: "초록 완료 · 주황 짧음 · 회색 예정"
- 보상 약속 카드: 문구 편집 가능 (기본 "저녁 양치 7일 연속 성공하면 주말에 놀이터 1시간!")
- 미양치 알림 토글 + 시각 (기본 21:00) — 제약은 3.6 참고
- 하단 링크: 설정

### 3.4 설정 (부모) — `#/settings`
- 부모 프로필: 프로필 이름(기본 "엄마·아빠", 최대 10자, 비우면 기본값), **로그아웃**
- 치카 타임 소리: 음성 안내 / 띵동 / 뽀글뽀글 / 배경 음악 켜기·끄기
- 아이 이름(호칭), 연령대(만 3세 미만 / 만 3~6세 / 만 7세 이상 — 표시용), 캐릭터 선택(토끼·곰·고양이)
- 시연 도구: 타이머 배속(×1 / ×10 / ×30, 주소에 `?speed=30`을 붙이면 설정보다 우선), **데모 데이터 채우기**(이번 주 시안과 비슷한 기록 생성), 데이터 전체 초기화(확인 2회)
  - **발표 모드 시간대 고정**: 자동 / 아침 / 저녁 — 발표가 낮(12~17시, slot `other`)에 있어도 새 기록이 달력·스탬프에 반영되게, 새로 시작하는 기록에 그 시간대를 붙인다

### 3.5 가상 본체 (전역 플로팅 패널)
- **화면에는 띄우지 않는다** (배포 전 결정). 기기 연결부(`device.js` 규약·`simulator.js`)는 남겨 두고, 키보드 `T`·`D` 단축키로 본체 버튼을 대신 누른다. 아래 LED·버튼 동작은 그 안에서 그대로 유지된다
- **LED**: 대기 시 `3:00`, 진행 중 남은 시간, 완료 시 `--:--` 깜빡임 후 `3:00`
- **타이머 버튼**: 대기 → 시작 / 진행 중 → 무시하고 LED 한 번 깜빡임 (아이 오조작 방지)
- **배출 버튼**: 시각 효과 + 토스트만
- 키보드 단축키 (발표용): `T` 타이머 버튼, `D` 배출 버튼, `1` 치카 타임, `2` 내 친구, `3` 부모 화면(엄마·아빠 프로필일 때만)

### 3.6 미양치 알림 (제약 명시)
- 서버가 없으므로 **페이지가 열려 있을 때만** 동작한다.
- 설정 시각이 지났는데 오늘 저녁 기록이 없으면: 화면 상단 배너 + (권한 허용 시) 브라우저 Notification
- 부모 화면에 "알림 미리보기" 버튼 → 즉시 배너 띄우기 (시연용)
- 발표 때 "실제 제품에서는 앱 푸시로 보낸다"고 설명

## 4. 규칙 (계산 로직)

### 4.1 양치 기록 (session)
- **타이머 버튼을 누른 순간** 기록 1건 생성 (제안서: 버튼 누른 시각 = 양치 1회)
- 상태
  - `completed`: 타이머가 0까지 감
  - `short`: 그만하기로 중지했거나, 진행 중 페이지가 닫혀 끝나지 못함
- `durationSec`: 실제 진행된 양치 시간(배속 적용된 시뮬레이션 시간), 최대 180

### 4.2 시간대 (slot)
| slot | 시간 |
|---|---|
| morning (아침) | 05:00 ~ 11:59 |
| evening (저녁) | 17:00 ~ 다음날 02:59 → 02:59까지는 **전날** 저녁으로 계산 |
| other (그 외) | 나머지 — 기록은 남지만 달력 점·실천율에는 안 들어감 |

- 세션에 `slotOverride`가 있으면 시각과 상관없이 **시작한 날짜의 그 시간대**로 본다 (발표 모드).

### 4.3 달력 칸 상태 (날짜 × slot)
- 해당 칸에 completed 1건 이상 → `done`
- completed 없고 short만 있음 → `short`
- 기록 없음 + 그 시간대가 아직 안 끝남 → `upcoming`
- 기록 없음 + 시간대가 지남 → `missed`

### 4.4 실천율
- 분모 = 이번 주(월요일 시작) 14칸 중 `upcoming`이 아닌 칸 수 (진행 중인 시간대라도 이미 기록이 있으면 4.3에 따라 done/short이므로 자동 포함)
- 분자 = 그중 `done` 칸 수
- 표기: `Math.round(분자/분모*100)%`, 분모 0이면 `-`

### 4.5 평균 양치 시간
- 이번 주 slot이 morning/evening인 기록의 `durationSec` 평균 → `m분 ss초`

### 4.6 스탬프·단계
- 스탬프 = **날짜 × slot 칸마다 첫 completed 1개당 1개** (버튼 연타로 쌓기 방지, 하루 최대 2개)
- 스탬프는 기록에서 **매번 계산**(저장하지 않음) → 데이터 꼬임 방지
- 단계 (조정 가능 — `js/domain/rewards.js` 상수 한 곳)
  | 단계 | 이름 | 필요 스탬프 |
  |---|---|---|
  | 1 | 아기 치카 | 0 |
  | 2 | 꼬마 치카 | 5 |
  | 3 | 치카 히어로 | 15 |
  | 4 | 치카 마스터 | 30 |

### 4.7 주간 퀘스트
- "저녁 양치 7일 연속 성공하기": 이번 주 월요일부터 **오늘까지** 저녁 칸이 연속 `done`인 일수 (오늘 저녁이 아직 `upcoming`이면 어제까지로 계산해 끊기지 않게)
- 7 달성 시 퀘스트 카드에 "성공! 보상 약속을 확인해요"

### 4.8 화면 접근 (`js/domain/auth.js` `resolveAccess`)
| 상태 | 가려는 화면 | 결과 |
|---|---|---|
| 로그인 전 | `/login` 외 전부 | `/login` |
| 로그인, 프로필 고르기 전 | `/profiles` 외 전부 | `/profiles` |
| 프로필 고른 뒤 | `/login`, `/profiles` | `/timer` |
| 아이 프로필 | `/parent`, `/settings` | `/timer` |
| 그 외 | | 그대로 |

## 5. 데이터 모델 (localStorage)

키: `chikacheck:v1` (JSON 1개)

```js
{
  schemaVersion: 1,
  auth: { loggedIn: false },        // 고른 프로필은 저장하지 않음
  child: { name: "우리 아이", ageGroup: "3-6", character: "rabbit" },
  parent: { nickname: "엄마·아빠" },
  sessions: [
    {
      id: "s_1729740000000",       // "s_" + 시작 시각(ms)
      startedAt: "2026-10-24T20:13:05+09:00",
      endedAt: "2026-10-24T20:16:05+09:00" | null,
      durationSec: 180,
      status: "completed" | "short" | "running",
      source: "device" | "screen", // 가상 본체 버튼 / 화면 시작 버튼
      speed: 1,                    // 시작할 때의 배속 (진행 중 복원용)
      slotOverride: null           // 발표 모드로 고정한 경우만 "morning"|"evening" (그날 dayKey 기준)
    }
  ],
  settings: {
    rewardPromise: "저녁 양치 7일 연속 성공하면 주말에 놀이터 1시간!",
    reminder: { enabled: true, time: "21:00" },
    sound: { voice: true, ding: true, bubble: true, bgm: true },
    demoSpeed: 1,
    demoSlot: "auto"             // "auto" | "morning" | "evening"
  }
}
```
- `slot`, 스탬프, 단계, 실천율은 **저장하지 않고 계산**한다.
- 앱 시작 시 `status: "running"` 기록이 있으면: `startedAt` 기준 경과 시간으로 타이머를 **이어서** 진행, 이미 3분이 지났으면 `completed`로 마감.
- 저장 형식이 바뀌면 `schemaVersion`을 올리고 `migrate()`에서 변환.

## 6. 기술 스택과 구조

- **Vanilla JS (ES Modules)**, 프레임워크·빌드 도구 없음, npm 의존성 없음
- HTML 1개 + 해시 라우터 (`#/login`, `#/profiles`, `#/timer`, `#/friend`, `#/parent`, `#/settings`) → GitHub Pages에서 새로고침해도 404 없음

## 부록 A. 나중에 실제 BLE 붙이기
- `js/device/device.js`의 규약만 지키면 `simulator.js` 대신 `ble.js`를 끼울 수 있다.
  - 기기 → 웹 이벤트: `timerButton` (버튼 누름)
  - 웹 → 기기 명령: `showTime(remainingSec)`, `showIdle()`, `blink()`
- Web Bluetooth는 **Android Chrome / 데스크톱 Chrome·Edge**만 지원, iOS Safari 미지원 → 발표 때 주의
- 보드 예: ESP32 (BLE GATT: 버튼 Notify 특성 1개 + 남은 시간 Write 특성 1개)
