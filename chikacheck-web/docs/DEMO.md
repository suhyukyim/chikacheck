# 발표 리허설 체크리스트

> 화면 이름·버튼 이름·단축키는 실제 코드 기준입니다.
> 단축키는 입력칸에 글을 쓰는 중에는 동작하지 않습니다. 한글 입력 상태여도 동작합니다.

## 발표 전날

- [ ] 휴대폰·노트북 둘 다 배포 주소가 열린다 (`https://<아이디>.github.io/chikacheck-web/`)
- [ ] 노트북 크롬 창 폭 1280px 이상 → 폰 화면이 가운데 보인다 (가상 본체 패널은 없음 — 본체 버튼은 키보드 `T`·`D`)
- [ ] 로그인 `chika` / `1234` → 프로필 **엄마·아빠** → 비밀번호 `0000` (시연은 이 프로필로: 탭 3개 다 보임)
- [ ] 하단 탭 **부모** → 맨 아래 **설정**
  - [ ] 치카 타임 소리: 발표장 스피커 확인, 필요하면 배경 음악만 끄기
  - [ ] 시연 도구 → **데모 데이터 채우기** → **바꾸기**
  - [ ] 타이머 배속 **×10** (3분 → 18초) — 더 빠르게 하려면 주소 끝에 `?speed=30` (6초)
  - [ ] 발표가 **12~17시**면 **발표 모드 시간대 고정: 저녁** (안 하면 새 기록이 '그 외' 시간이라 달력·스탬프에 안 나옴)
  - [ ] 치카 타임 화면 위에 "발표 모드 · 새 기록은 오늘 저녁 칸에" 표시가 보이는지 확인
- [ ] 부모 화면이 시안처럼 보이는지: 실천율 80%대, 평균 2분 40초대, 주황(짧음) 1개, 오늘 저녁 칸은 회색(예정)
- [ ] 내 치카 친구: "2단계 · 꼬마 치카", 퀘스트 4/7 근처
- [ ] 와이파이가 없을 때 대비: 노트북에 Live Server 버전도 준비 (글꼴만 기본 글꼴로 바뀌고 기능은 그대로)

## 시연 (약 1분)

시작 화면: **치카 타임** (단축키 `1`)

1. "아이가 칫솔을 꺼내고" → 키보드 `D` (본체 배출 버튼)
   → 방울이 떨어지고 "완두콩만큼 나왔어요!" (배출은 기계식이라 기록하지 않는다고 설명)
2. 키보드 `T` (본체 타이머 버튼) 또는 **화면에서 시작**
   → 화면의 링이 3분부터 줄어든다
   → 30초마다 "지금은 ○○!" 구역이 바뀌고, 이빨 친구의 빛나는 면·볼/혀·3D 입 지도가 함께 바뀌며 음성으로 안내한다
   → (소리는 화면이나 본체 버튼을 한 번 누른 뒤부터 난다 — 브라우저 정책)
   → (진행 중에 `T`를 또 눌러도 기록은 늘지 않음 — 아이 오조작 방지)
3. 완료 → 색종이 + "다 닦았다! 🎉" + "스탬프 1개 받았어요" → **확인**
4. `2` → **내 치카 친구**: 스탬프 진행 바, 오늘의 출석(저녁 채워짐), 이번 주 퀘스트 +1
5. `3` → **양치 기록**: 달력 오늘 저녁 점이 초록, 실천율·평균 시간 갱신
   → (아이 프로필이면 부모 탭이 없다는 것도 보여 주기: 상단 프로필 버튼 → 아이 선택 → 탭 2개)
6. **알림 미리보기** → 상단 배너 "오늘 저녁 양치 기록이 아직 없어요"
   → "앱이 열려 있을 때만 동작하고, 실제 제품에서는 앱 푸시로 보낸다"고 설명

## 막혔을 때

| 증상 | 해결 |
|---|---|
| 완료했는데 달력·스탬프가 그대로 | 낮 시간(12~17시)이면 설정 → 발표 모드 시간대 고정: 저녁 |
| 타이머가 너무 느림 | 설정 → 타이머 배속 ×10, 또는 주소에 `?speed=30` |
| 새로고침했더니 프로필 선택이 나옴 | 정상 (고른 프로필은 저장하지 않음). 엄마·아빠 → `0000` |
| 소리가 안 남 | 화면을 한 번 누른 뒤 다시 시작 / 설정 → 치카 타임 소리 켜졌는지 / 기기 무음 모드 확인 |
